# Content And Copy Plan

## Homepage Copy Direction

Hero headline:

> Secure, SEO-ready websites for Indian businesses.

Hero support:

> Chaitanya Media builds website infrastructure, Google visibility systems, and website protection for businesses that depend on trust, search, and WhatsApp inquiries.

Primary CTA:

> Get Free Website / SEO Audit

Secondary CTA:

> WhatsApp Consultation

Hero trust line:

> Cisco, Google Cybersecurity, Semrush SEO, MSME, GST, since 2020.

Use only after owner verifies exact credential names and registration details.

## Homepage Section Order

1. Hero
2. Trust strip
3. Choose your problem
4. Core service pillars
5. Why website, SEO, and security belong together
6. Audit-first process
7. Proof and credentials
8. Blog / knowledge section
9. Final CTA

## Choose Your Problem

Use buyer language:

- My website looks outdated.
- My website is slow.
- My website is not ranking.
- My Google Business Profile is weak.
- My website has SSL or security issues.
- My emails go to spam.
- I need a new website before running ads.
- I need automation after my foundation is fixed.

Each problem should map to a service page and CTA.

## Service Page Copy Formula

Each service page should follow:

1. Problem.
2. Diagnosis.
3. What Chaitanya Media builds or fixes.
4. What is included.
5. What is not promised.
6. Proof assets.
7. Process.
8. FAQ.
9. CTA.

## Blog Migration Plan

Keep and improve:

- SSL / not secure warning.
- SPF, DKIM, DMARC.
- Customer data exposure.
- Google Business Profile local SEO.
- Website development basics.
- Hosting, domain, SSL, speed, and security posts.

Rework:

- `UI/IX Design` should become `UI/UX Design`.
- Abstract thought-leadership posts should be categorized separately or rewritten with practical business takeaways.
- `Uncategorized` should be removed from public blog taxonomy.

Recommended categories:

- Website Security.
- Technical SEO.
- Local SEO.
- Website Infrastructure.
- Email Deliverability.
- Case Studies.
- Automation and AI.

## FAQ Themes

Website Infrastructure:

- How much does a business website cost?
- How long does it take?
- Can you improve an existing WordPress website?
- Will the website be SEO-ready?
- Do you provide hosting and domain support?

SEO:

- What is technical SEO?
- How long does SEO take?
- Do you guarantee rankings?
- Can you optimize Google Business Profile?
- What is included in an SEO audit?

Security:

- Can you fix SSL warnings?
- Can you remove WordPress malware?
- Do you need admin access?
- Do you guarantee a website can never be hacked?
- Do you work only with authorized website owners?

Automation:

- When should a business add automation?
- Can WhatsApp or CRM flows be automated?
- Do you build AI assistants?
- What business data is needed?

## Copy Guardrails

Use:

- Clear.
- Practical.
- Trustworthy.
- Buyer-first.
- Technical after the buyer pain is clear.

Avoid:

- Heavy spiritual language on service pages.
- Overuse of "infrastructure".
- Long abstract paragraphs.
- Multiple competing CTAs.
- Claims without proof.

Tone:

- Calm technical confidence.
- Indian SMB friendly.
- Founder-led but not founder-only.
- Practical and audit-first.
