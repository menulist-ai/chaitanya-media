## Useful Patterns

- Supahub / provided Grabee screenshot: centered hero, product-browser mockup, numbered loop, section proof directly below CTA.
- Gamma: clear product categories and visual-first cards; useful as inspiration for reducing scattered copy.
- Overflow: one strong visual surface with tabbed presentation modes; useful for campaign-system storytelling.
- Protoio Inc: restrained white space, large typography, simple proof chips over real visuals.
- Dock: revenue/workspace framing, tabbed product preview, bold metric cards, proof strip before the deeper product story.
- Outseta: all-in-one operating-system message, browser-like module cards, dotted surface texture, compact status labels.
- Peppermint: high-impact hero illustration and simple CTA focus; too decorative for Chaitanya Media, so not copied.
- Front: dark hero with feature tabs and one central customer-operation visual; useful for a future dark-mode hero variant, but too SaaS-heavy for Chaitanya Media right now.

## Applied To Chaitanya Media

- Added a product-style campaign workspace preview under the homepage hero.
- Converted the campaign engine section into a closed-loop visual with four stages around a central system card.
- Added a service-browser panel beside the service groups so services feel like a guided stack instead of only a card list.
- Softened service-group borders and improved mobile collapse behavior.

## Not Applied

- Purple-first SaaS gradients from Gamma, Supahub, Peppermint, and Front.
- Abstract product language that would make Chaitanya Media feel like a software company.
- Large decorative illustration-first hero, because Chaitanya Media needs service clarity and local trust.
