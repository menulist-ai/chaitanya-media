# Launch And QA Checklist

## Owner Verification

Confirm before final build:

- Business legal name.
- Brand name display.
- GST number.
- MSME/Udyam proof.
- Canonical phone number.
- Canonical WhatsApp number.
- Canonical email.
- Address or service-area model.
- Business hours.
- Google Business Profile URL.
- Verified public profile URLs.
- Credential links.
- Portfolio permission.
- Testimonials permission.
- Legal page approval.

## Content QA

- No fake metrics.
- No ranking guarantees.
- No absolute security guarantees.
- No unsupported certification claims.
- All phone and WhatsApp links work.
- Email is consistent everywhere.
- CTA text is consistent.
- Blog categories are clean.
- Old typo URLs are redirected.

## SEO QA

- Every indexable page has title, description, canonical.
- Sitemap includes only valid indexable URLs.
- Robots allows important pages.
- Thank-you page is noindex.
- Removed shop/account pages are noindex or redirected.
- Structured data validates.
- Breadcrumbs are correct.
- Internal links work.
- 404 page exists.
- Redirect map tested.
- Search Console property ready.

## Performance QA

- No oversized hero image.
- Images use responsive sizing.
- Font loading is controlled.
- Mobile layout does not shift.
- Forms and buttons do not resize unexpectedly.
- Core Web Vitals tested after deploy.

## Security QA

- HTTPS enforced.
- Security headers configured.
- CSP reviewed after scripts are known.
- Forms do not request credentials.
- Security service page includes authorization boundary.
- Legal pages linked in footer.
- Admin or private routes are not exposed.

## UX QA

Desktop:

- Header works.
- Dropdown works.
- CTAs are visible.
- Service pages scan cleanly.
- Contact routes are obvious.

Mobile:

- Navigation opens and closes.
- CTA is reachable.
- WhatsApp link works.
- Text does not overflow.
- Cards stack cleanly.
- Buttons fit.

## Launch Steps

1. Freeze final URL map.
2. Export old WordPress sitemap.
3. Add redirects.
4. Build production bundle.
5. Run lint/typecheck/build.
6. Test deployed preview.
7. Test forms and links.
8. Submit sitemap.
9. Inspect top URLs in Search Console.
10. Monitor 404s and analytics for 30 days.

## Post-Launch Growth

Monthly:

- Add one proof asset.
- Publish two to four practical posts.
- Update GBP.
- Request reviews.
- Check Search Console.
- Improve CTAs based on lead quality.
- Add case studies.
- Monitor Core Web Vitals.
- Maintain security and backups.
